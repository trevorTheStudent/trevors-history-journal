# U.S. History Journal

A simple multi-page static website for Trevor Whitehead's U.S. History Journal.

## Project structure

- `index.html` — journal homepage and entry list
- `entries/entry-1.html` — The City and Its Workers
- `entries/entry-2.html` — starter page for the second journal entry
- `styles.css` — shared styling for every page
- `images/` — images used by journal entries

## Edit locally

Open this folder in VS Code. Edit the HTML files directly, then open `index.html` in a browser or use VS Code's Live Server extension to preview the site.

## Publish with GitHub Pages

Commit and push the files to the repository used by GitHub Pages. In the repository settings, configure Pages to deploy from the root of the main branch.

When adding more entries, copy `entries/entry-2.html`, rename the copy, and add a new card to `index.html`.
